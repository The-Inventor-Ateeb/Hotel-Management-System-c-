# 🏨 Hotel Management System

A console-based **Hotel Management System** developed in **C++**. This project uses **file handling** to store and manage hotel booking records.

## ✨ Features

* 🛏️ Book a room
* 👤 Add and view customer records
* 📋 View all booked rooms
* ✏️ Edit customer/booking records
* 🗑️ Delete booking records
* 🔍 Check room availability
* 💰 Calculate total hotel revenue
* 💾 Store records using file handling

## 🛠️ Technologies Used

* C++
* Structures
* Functions
* File Handling (`fstream`)
* Input/Output Formatting

## 📂 Data Storage

The booking records are stored in a text file named:

`hotel_records.txt`

## 🎯 Project Purpose

This project was developed to practice **C++ programming, structures, functions, file handling, and basic management-system concepts**.
